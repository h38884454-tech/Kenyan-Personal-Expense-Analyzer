# Kenyan-Personal-Expense-Analyzer
A beginner friendly Python data analytics project exploring spending patterns using pandas Matplotlib

## Run the notebook

Install the dependencies with `pip install -r requirements.txt`, then open `kenyan_personal_expense_analyzer.ipynb` in Jupyter or VS Code and run the cells in order.

The upload panel imports CSV statements with date and amount columns, saves receipt images and PDFs in `uploaded_receipts/`, and lets you add receipt transactions manually. Receipt files are not OCR-processed. Uploads stay in the local project folder; do not use a shared workspace for sensitive financial documents.
